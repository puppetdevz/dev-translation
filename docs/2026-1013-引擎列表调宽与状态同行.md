# 引擎列表调宽与状态同行

## 需求与实现

依据用户截图：设置页「引擎」左侧列表支持拖动调整宽度；主引擎、已关闭、未配置状态移到 P 序号左侧，不再显示在名称下方。

- 实现位置：`src/Translate/components/SettingsPage.vue`，只调整活跃设置页，不修改引擎调用、启停、拖拽排序与持久化语义。
- 列表默认宽度 280px，最小 240px、最大 420px；根据容器实时限制上限，为右侧配置保留至少 280px（分隔区域共 16px）。宽度仅在当前页面保留，离页重进恢复默认，不新增设置字段。
- 中间分隔条提供 12px 指针命中区域、浅/深色悬停与焦点反馈。Tab 聚焦后，左右方向键每次调整 10px，Home / End 到允许边界；提供 separator / vertical / 数值范围及当前宽度的可访问语义。
- 窗口与布局变化自动收敛宽度；指针释放、取消、窗口失焦、切换分类、缩至窄窗和组件卸载均停止拖动，卸载移除监听与布局观察器。
- 状态成为名称容器外的独立不换行元素，紧邻 P 序号左侧；两个状态同时出现也保持同行。长名称省略显示，可悬停查看完整名称。
- ≤640px 隐藏分隔条，保持列表在上、详情在下；卡片换行基础宽度改为 240px，避免同行状态挤压名称。详情标题栏唯一启停入口保持不变。
